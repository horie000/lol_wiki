## 解釈上の限界

- 試合時間は勝敗後に確定するため、時間帯別勝率はパワースパイクの因果効果を示さない。
- パッチ、ロール、観測ランク帯、チャンピオン選択、試合展開が混在する。特に全パッチ合算はパッチ差の影響を受ける。
- 最終的な分類は各時間帯の標本数を揃えた記述的なスクリーニングであり、推奨や確定的な序盤・中盤・終盤判定ではない。
