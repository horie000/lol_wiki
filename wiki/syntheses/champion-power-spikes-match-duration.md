# チャンピオンのパワースパイク：試合時間帯別勝率の見直し

## 問い

Data Dragonの能力説明・基礎ステータスから作成した既存のパワースパイク分類を、収集済みランク戦の試合時間と勝率から見直す。原典から読める能力上の成長と、試合結果から観測される時間帯別の勝率は異なる概念なので、同じ区分へ機械的に統合せず、二つの証拠層として比較する。

## 結論

4,672件の完全試合を5つの時間帯に分け、各帯15試合以上のチャンピオンだけを対象に記述的なスクリーニングを行った。その結果、時間帯別勝率から明瞭な差を抽出できたのは47件で、序盤寄り11、中盤寄り22、終盤寄り14だった。75件は5帯の分母を満たすものの明瞭な傾向がなく、51件は分母不足で判定を保留した。

この結果は、既存の原典ベース分類を置き換えるものではない。たとえばスモルダーとチョ＝ガスは原典上の成長シグナルと終盤寄りの観測が整合する一方、カイ＝サとラックスは原典上の終盤・中盤シグナルに対して序盤寄りの観測となった。逆に、ヴェイン、ザヤ、セジュアニは原典分類では中盤または序盤を主とするが、今回のデータでは終盤寄りだった。これはパッチ、ロール、構成、選択される試合、勝敗による試合時間の決定を含む記述差であり、能力そのものの因果的なパワースパイクとは断定できない。

## 解析方法

| 項目 | 条件 |
| --- | --- |
| 入力 | `raw/sources/riot-ranked-matches/`、Match-v5のローカル収集データ |
| キュー | `420` |
| 重複処理 | 試合ID単位で統合、`tier_mode=all` |
| 完全試合 | 10参加者、2チーム各5人、勝敗と試合時間が解決できる試合 |
| 時間帯 | 〜20分、20〜25分、25〜30分、30〜35分、35分〜 |
| 分母条件 | 各時間帯15試合以上 |
| 観測分類 | 最高勝率帯が端点の場合に端点差8ポイント以上、または中間帯が両端点より8ポイント以上 |

8ポイントという閾値は、候補を整理するための再現可能な運用規則であり、統計的有意性の検定や信頼区間による採択基準ではない。詳細な各チャンピオンの分子・分母、Wilson区間、時間帯別勝率は、解析レポートの `champion-duration-winrate.csv` と `champion-duration-winrate.json` に保存した。

## 試合時間の分布

中央値は29分18秒、P10〜P90は16分48秒〜39分45秒だった。

| 時間帯 | 試合数 | 割合 |

| 〜20分 | 758 | 16.2% |
| 20〜25分 | 665 | 14.2% |
| 25〜30分 | 1,084 | 23.2% |

| 35分〜 | 1,074 | 23.0% |

## 観測分類の内訳

| 実戦データ上の分類 | チャンピオン数 | 意味 |
| --- | ---: | --- |
| 序盤寄り | 11 | 〜20分の勝率が最高で、35分〜との差が8ポイント以上 |
| 中盤寄り | 22 | 20〜35分のいずれかが最高で、両端点との差が8ポイント以上 |
| 終盤寄り | 14 | 35分〜の勝率が最高で、〜20分との差が8ポイント以上 |
| 明瞭な傾向なし | 75 | 上記の差を満たさない、または勝率が非単調 |
| 判定保留（分母不足） | 51 | 5帯のいずれかが15試合未満 |

## 原典分類との関係

既存の[[wiki/syntheses/champion-power-spikes-v16-18-1|原典ベース分類]]は、能力説明・基礎ステータスから「成長する仕組み」を記述する。一方、このページの分類は、実際にそのチャンピオンを含む試合が長さごとにどの勝率を示したかを記述する。

| 例 | 原典ベース分類 | 試合時間別の観測 | 読み方 |
| --- | --- | --- | --- |
| [[wiki/entities/champions/smolder\|スモルダー]] | 終盤 | 終盤寄り | スタック成長と時間帯傾向が同方向だが、因果効果ではない。 |
| [[wiki/entities/champions/chogath\|チョ＝ガス]] | 序盤・終盤 | 終盤寄り | 基礎ステータスの序盤シグナルは、今回の時間帯分類では確認されない。 |
| [[wiki/entities/champions/kaisa\|カイ＝サ]] | 終盤 | 序盤寄り | アイテムによるスキル強化の存在だけでは、実戦の時間帯別勝率を予測できない。 |
| [[wiki/entities/champions/lux\|ラックス]] | 中盤 | 序盤寄り | 短時間帯での勝率差は、構成・ロール・試合展開を含む観測値である。 |
| [[wiki/entities/champions/vayne\|ヴェイン]] | 中盤 | 終盤寄り | 長時間帯の観測は、原典に明示的な蓄積シグナルがないことと矛盾し得る。 |

> [!warning] 原典分類との未解決の矛盾
> 原典の能力シグナルと、試合時間帯別勝率が一致しないチャンピオンが多数ある。これはどちらかを黙って置き換えるのではなく、能力の仕組みと試合結果の関連が別の問いであることを示す。パッチ・ロール・観測帯を固定した追加分析が必要である。

## 含意

- 既存の個別ページでは原典ベースの `## パワースパイク` を保持し、同じページに実戦データの観測ブロックを追加する。
- 「終盤寄り」は35分以降の勝率が高かったという意味であり、35分まで待つべき、終盤のビルドが最適、という推奨ではない。
- 「明瞭な傾向なし」は均一に強いという意味ではなく、今回の時間帯・分母・混合集計では閾値を超える差が確認できなかったという意味である。
- 解析期間が48パッチにまたがるため、現在パッチの判断には同一パッチまたは直近パッチの再集計を優先すべきである。

## 未解決の問い

- ロール別・パッチ別に分けたときも、序盤・中盤・終盤の観測が再現するか。
- Timelineデータで15分、25分、35分時点のゴールド・経験値・装備状態を直接比較できるか。
- 原典の成長シグナルと時間帯別勝率を、試合選択とパッチを調整したモデルで比較できるか。
