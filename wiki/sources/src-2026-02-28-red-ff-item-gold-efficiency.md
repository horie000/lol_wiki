# アイテムの金銭効率ランキング：ファイター編【LoL】

## 要約

レッド＆ふぉーの記事は、パッチ26.4のファイター系アイテムを対象に、基準アイテムから算出した「1ステータスあたりの金額」を使って金銭効率を比較している。記事本文の公開日は2026-02-28、更新日は2026-03-11である。金銭効率は、アイテムのステータスを金額へ換算した合計を実購入価格と比較する指標で、固有効果の価値は原則として含めない。

## 主要な主張

- 基本ステータスの単価は、マナ1、体力2.67、基本体力自動回復3、基本マナ自動回復4、移動速度12、物理防御20、魔法防御20、魔力20、攻撃速度25、攻撃力35、クリティカル率40、スキルヘイスト50 gold/stat である。
- 追加の単価として、行動妨害耐性10.33、脅威30、物理防御貫通（割合）41.67、魔法防御貫通（割合）46.15、魔法防御貫通（固定）46.67、回復効果およびシールド量50、ライフスティール53.57、割合移動速度62.5 gold/stat を示している。
- 行動妨害耐性は、1250ゴールドの基準アイテムから他の基礎ステータス分310ゴールドを差し引き、30%で割って10.33 gold/%と算出している。したがって、ステラックの籠手やウィッツ エンド等の行動妨害耐性を持つアイテムにも単価を適用できる。
- オムニヴァンプ、アルティメットヘイスト、固有効果・発動効果は、記事のランキングでは基本ステータスの比較から除外している。金銭効率が低くても、固有効果やチャンピオンとの相性で実戦価値は変わる。

## 根拠と限界

- 本リポジトリでは、この記事の単価表を Data Dragon v16.18.1 の全アイテムページへ適用する。記事の対象はファイター系だが、単価表そのものは個別アイテムの基礎ステータス換算に使えるものとして扱う。
- 2017年のFirstBloodStats記事とは、魔力、マナ、魔法防御、スキルヘイスト、脅威、貫通、ライフスティール等の単価が異なる。現行の一括算定では、本記事を優先し、固定通常攻撃時追加ダメージだけは本記事に単価がないためFirstBloodStatsの25 gold/statを補助的に使う。この選択は方法上の近似であり、両記事の値が同一のゲーム内真値だという意味ではない。
- 記事はパッチ26.4を前提とし、Wikiのアイテム原典はData Dragon v16.18.1である。版・アイテム状態の差分があるため、算定値は採用した単価表による比較値として読む必要がある。
- クリティカルダメージ、オムニヴァンプ、アルティメットヘイスト、条件付き・動的な自動効果など、記事に直接の単価がない項目は根拠のない換算を避けて対象外とする。
