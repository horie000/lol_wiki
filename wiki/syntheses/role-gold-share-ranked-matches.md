# ランク戦におけるロール別ゴールド獲得シェア

## 問い

収集済みランク戦では、各ロールがチームの累積獲得ゴールドをどの程度の割合で占めるか。また、その割合は勝敗、試合時間、観測ランク帯によってどのように異なるか。

> [!warning] 指標の定義
> ここでの「所持率」は、試合終了時の `goldEarned` によるチーム内ゴールド獲得シェアである。未使用の現在ゴールド、購入額、特定時点の保有額ではない。

## 結論

完成済み3,991試合の観測では、平均シェアはボット22.69%、ジャングル21.49%、ミッド20.17%、トップ20.12%、サポート15.53%だった。ボットが最大、サポートが最小であり、ミッドとトップは0.04ポイント差でほぼ同水準だった。

記述的には、長い試合ほどボットの比率が高く、サポートの比率が低かった。20分未満から35分以上への差はボット+1.47ポイント、サポート-1.33ポイントである。勝利側では敗北側よりボットの比率が+0.49ポイント、サポートが-0.46ポイントだった。ただし、これらは試合展開の結果を含む最終スコア上の関連であり、資源配分戦術の因果効果ではない。

## 分析方法

| 項目 | 条件 |
| --- | --- |
| 入力 | `raw/sources/riot-ranked-matches/**/matches.jsonl` の完成済み4本 |
| キュー | `420` |
| 観測帯 | IRON、BRONZE、SILVER、GOLD、各1,000入力レコード |
| 重複処理 | 試合ID単位、`tier_mode=all` |
| 適格試合 | 2チーム各5人、各チームにTOP/JUNGLE/MIDDLE/BOTTOM/UTILITYが1人ずつ、正の `goldEarned` と試合時間、勝敗を確認できる試合 |
| 分母 | 3,991試合、7,982チーム、各ロール7,982観測 |
| 期間 | 2026-01-27〜2026-09-14、17パッチ |

各チームで `参加者のgoldEarned ÷ チーム5人のgoldEarned合計` を求め、その割合をチーム単位で平均した。これを主指標の「平均シェア」とする。プール比は全試合のゴールド総量で重み付けされるため、長時間試合や高ゴールド試合の影響をより強く受ける。

## キャッシュ込み標本による感度確認

完成済み4本だけの主分析と、収集キャッシュを含む9,938試合を比較した。後者は2024-09-25〜2026-09-14の48パッチを含む別標本である。

| ロール | 完成済み標本 | キャッシュ込み | キャッシュ込み−完成済み |
| --- | ---: | ---: | ---: |
| トップ | 20.12% | 20.34% | +0.21pp |
| ジャングル | 21.49% | 21.48% | -0.01pp |
| ミッド | 20.17% | 20.36% | +0.19pp |
| ボット | 22.69% | 22.38% | -0.31pp |
| サポート | 15.53% | 15.44% | -0.09pp |

標本を広げても順位は変わらず、差は最大0.31ポイントだった。これは主な順位がキャッシュの採否だけで反転しないことを示す感度確認であり、母集団への一般化を保証するものではない。

## 解釈

以下は観測値からの推論であり、原典に明示されたゲーム設計上の規則ではない。

- ボットのマクロ平均22.69%に対してプール比が22.90%と高く、サポートは15.53%に対して15.35%と低い。ゴールド総量の大きい試合ほどボット側へ比率が寄るという時間帯別の並びと整合する。
- ミッドとトップの平均差は0.04ポイントしかなく、この混合集計から両者の明確な序列を主張するのは適切でない。
- 勝利側でボット比率が高く、サポート比率が低い関連は、キル、タワー、ファーム、試合時間、チャンピオン構成のどれによるものか分離できない。ボットへ資源を集めれば勝てる、という戦術推奨には変換できない。

## 矛盾と不確実性

「所持率」という語は現在ゴールドを意味し得るが、Match-v5の最終スコアから安定して比較できるのは累積 `goldEarned` である。この定義差は未解決ではなく、本分析では「チーム内累積獲得シェア」として限定した。固定時点または未使用ゴールドを問う場合はTimeline等の別データが必要である。

## 未解決の問い

- 10分、15分、20分など固定時点では、ロール別シェアの順位と差がどう変化するか。
- チャンピオン、パッチ、試合時間を固定した場合にも、勝敗別のシェア差が残るか。
- 観測帯ではなく参加者全員の試合時ランクを確認した標本でも、ボットとサポートの帯別の並びが再現するか。
